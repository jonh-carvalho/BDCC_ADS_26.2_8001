# O que é o Hadoop?

Hadoop é um framework de software de código aberto projetado para armazenar e processar grandes volumes de dados distribuídos em clusters de computadores. Ele foi inspirado pelo modelo MapReduce desenvolvido por Google e é amplamente utilizado em ambientes de big data.

## Componentes principais do Hadoop:

### 1. HDFS (Hadoop Distributed File System)
- Sistema de arquivos distribuído que armazena dados em vários nós
- Garante alta disponibilidade e tolerância a falhas
- Divide os arquivos em blocos e replica esses blocos em diferentes máquinas

### 2. MapReduce
- Modelo de programação para processamento paralelo de grandes conjuntos de dados
- Divide o trabalho em duas fases: mapeamento e redução
- Permite processar dados em paralelo em clusters

### 3. YARN (Yet Another Resource Negotiator)
- Gerenciador de recursos do cluster
- Responsável por alocar recursos aos aplicativos
- Facilita a execução de diferentes tipos de aplicativos no mesmo cluster

## Características principais:

- **Escalabilidade horizontal**: Pode escalar adicionando mais máquinas ao cluster
- **Tolerância a falhas**: Detecta e recupera automaticamente de falhas de hardware
- **Processamento distribuído**: Distribui o processamento em várias máquinas
- **Armazenamento de dados não estruturados**: Suporta diferentes tipos de dados

## Casos de uso comuns:

- Análise de grandes volumes de dados
- Processamento de logs e eventos
- Machine learning e inteligência artificial
- Armazenamento de dados de sensores e IoT
- Análise de redes sociais e comportamento do consumidor

## Vantagens:

- Custo reduzido em comparação com soluções proprietárias
- Flexibilidade para diferentes tipos de dados
- Escalabilidade linear com o aumento do hardware
- Comunidade ativa e suporte amplo

## Desvantagens:

- Não é adequado para operações em tempo real
- Complexidade de configuração e administração
- Overhead de processamento para tarefas simples
- Necessidade de conhecimento técnico avançado

O Hadoop se tornou uma solução fundamental para empresas que precisam lidar com grandes volumes de dados, oferecendo uma alternativa escalável e econômica para armazenamento e processamento distribuído.
